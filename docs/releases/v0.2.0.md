# Nest Player 0.2.0 — website playback, SMB folders, and iPhone remote

- Paste YouTube/Bilibili URLs or share text into the playlist and stream audio
  to Cast, with local H.264 video preview up to 720p when available.
- Load media through a range-capable local relay without first downloading the
  whole video. Completed responses use a 512 MB cache budget.
- Sign in through the normal website in your chosen browser; cookie access is
  explicit, optional, and kept in memory. No password form is added to the app.
- Import local or Finder-mounted SMB folders with cancellable background scans,
  natural sorting, deduplication, and persistent offline NAS entries.
- Open **Phone Remote** and scan its QR code from iPhone, or use the shown LAN
  address and pairing code. Control transport, seeking, volume, playlist, Mac
  audio, and pasted website links.

## Install

Download `Nest-Player-0.2.0-macOS-arm64.zip`, extract it, and move Nest Player.app
to Applications. Requires Apple Silicon and macOS 14+. Python, PyChromecast,
yt-dlp, and EJS scripts are bundled. External tools:

```bash
brew install ffmpeg deno
```

FFmpeg handles local format conversion; Deno solves YouTube's JavaScript
challenges. Node 22+ can be used instead of Deno. Browser login cannot bypass
website access restrictions. Live streams and full-site playlists are not
supported. SMB shares must remain mounted on the Mac.

The app is ad-hoc signed and not notarized by Apple. If macOS blocks the app and
you trust this release, use **System Settings → Privacy & Security → Open Anyway**
after attempting to open it. See [Apple's instructions](https://support.apple.com/en-us/102445).

Verify the ZIP with its attached SHA-256 file. The source and packaged resolvers
were tested with public YouTube and Bilibili videos without personal cookies or
audible playback. Login consent, HTTP range delivery/cache, pairing permissions,
folder scanning, and playlist persistence are covered by automated tests. The
phone controller was exercised in a browser at 390-pixel mobile width. A real
personal account, specific NAS, and physical iPhone remain environment-dependent.
