# Nest Player 0.1.0 — Google Cast audio player for macOS

The first public release of Nest Player: a native Mac player for local music,
podcasts, and video soundtracks on Google Nest / Google Home / Google Cast
speakers.

## Download

- `Nest-Player-0.1.0-macOS-arm64.zip` contains **Nest Player.app**.
- `Nest-Player-0.1.0-macOS-arm64.zip.sha256` contains its SHA-256 checksum.
- Requires **Apple Silicon (M1 or newer), macOS 14+**, and a Cast speaker on
  the same LAN. No Intel binary is included.

Extract the ZIP, move the app to Applications, open it, choose a speaker, and
add a media file. Python and PyChromecast are bundled. Install FFmpeg separately
for video soundtrack extraction and unsupported audio formats:

```bash
brew install ffmpeg
```

The app is ad-hoc signed and **not notarized by Apple**. If macOS blocks it and
you trust the download, attempt to open it, then use **System Settings →
Privacy & Security → Open Anyway**. See
[Apple's instructions](https://support.apple.com/en-us/102445).

## Included

- Native SwiftUI interface with the original Nest Player app icon.
- Drag-and-drop playlist, reorder, previous/next, and automatic advancement.
- Local video with Cast audio; Mac sound is muted by default and optional.
- Pause, resume, stop, seek, and Cast volume controls.
- One persistent Cast service and remembered speaker discovery results.
- Direct playback, compatible audio stream extraction, and cached conversion.
- Generation-based stale-command rejection and a bounded playback-start deadline.
- Python CLI, JSON interface, and a repository-local Cast skill.

## Verification and limitations

Swift and Python regression tests pass. The packaged helper starts without
system Python or `uv`, including from an unrelated directory, and the `.app`
signature is verified. The release ZIP is extracted and signature-checked
before upload. A Google Nest Mini was used for the original LAN playback test;
other receiver models and older supported macOS versions have not all been
tested.

FFmpeg is external, local picture playback depends on AVFoundation codec
support, and dual audio is not sample-synchronized. Cloudflare remote control,
system-audio capture, video casting, notarization, and automatic updates are
not included in 0.1.0.
