# Nest Player 0.3.1 — volume fix

- **Volume works again.** Changing volume showed “'Chromecast' object has no
  attribute 'receiver_controller'” and never reached the speaker. The Mac
  slider, the phone remote, `nest-speaker volume`, and `play --volume` now set
  the Cast volume.
- **Sleep timer fade.** Because it uses the same path, the 0.3.0 sleep timer's
  30-second fade-out and the volume restore after stopping now take effect.

## Install

Download `Nest-Player-0.3.1-macOS-arm64.zip`, extract it, and move Nest
Player.app to Applications. Requires Apple Silicon and macOS 14+. Install
FFmpeg for video soundtrack handling and Deno for YouTube:

```bash
brew install ffmpeg deno
```

The app is ad-hoc signed and not notarized by Apple; see the README's
first-launch instructions. Verify the ZIP with its attached SHA-256 file.
