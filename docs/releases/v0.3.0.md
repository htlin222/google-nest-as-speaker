# Nest Player 0.3.0 — playlists, resume, sleep timer, alarms

- **Multiple named playlists.** Switch, create, rename, and delete playlists
  from the sidebar; copy tracks between them with **Add to Playlist**. Your
  existing playlist moves into “預設” on first launch.
- **Resume.** Each playlist remembers its track and position and continues
  there when you press Play.
- **Playlist editing.** Multi-select and remove with the Delete key, rename
  tracks, sort by name, and confirm before **Clear**.
- **Repeat.** Off → whole playlist → current track, saved per playlist.
- **Sleep timer.** Stop after 15–90 minutes or at the end of the track, with a
  30-second fade-out; the speaker volume is restored afterwards.
- **Alarms.** Start a playlist at a set time on chosen weekdays. Nest Player
  must be open and the Mac awake; alarms never change volume or interrupt
  playback.
- **Phone remote.** Switch playlists and set repeat and the sleep timer from
  the phone. Pairing now lasts across launches, so a Home Screen shortcut pairs
  once; **Reset Pairing** on the Mac unpairs every phone.

## Fixes

- Playback no longer reports “Cast playback ended: UNKNOWN” and loses control
  while the speaker is still playing.
- Closing the window now quits the app and stops casting instead of leaving it
  running invisibly.

## Install

Download `Nest-Player-0.3.0-macOS-arm64.zip`, extract it, and move Nest
Player.app to Applications. Requires Apple Silicon and macOS 14+. Install
FFmpeg for video soundtrack handling and Deno for YouTube:

```bash
brew install ffmpeg deno
```

The app is ad-hoc signed and not notarized by Apple; see the README's
first-launch instructions. Verify the ZIP with its attached SHA-256 file.
