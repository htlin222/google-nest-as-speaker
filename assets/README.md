# Nest Player logo

`nest-player.png` is the original, alpha-transparent master used by the README
and the macOS icon build. The build generates all icon sizes and `NestPlayer.icns`
with macOS `sips` and `iconutil`.

Created with the built-in image generation tool, using the supplied Google Cast
logo as a concept reference for wireless casting. The independent design uses
a midnight indigo tile, white play symbol, and turquoise broadcast arcs.

## Generation prompt

> Use case: logo-brand. Asset type: production macOS app icon and GitHub project logo for Nest Player, an independent Mac app that plays local audio on Google Cast speakers. Input Image 1 is a visual reference for the simple wireless casting concept ONLY, not an edit target. Create ONE original icon, square 1024x1024 composition. A deep midnight indigo rounded-square macOS tile, almost filling the canvas with about 6% transparent margin outside, with a very subtle indigo depth gradient. Within it, a bold clean white rounded right-facing play triangle in the center-right, paired with two thick turquoise quarter-circle broadcast arcs and a turquoise dot radiating from lower-left; compose these into one beautifully balanced, distinctive geometric mark conveying play + audio casting. Use generous negative space, uniform rounded ends, strong silhouette, legible at 32 pixels, flat vector-like precision. Keep the arc geometry simple and airy, play symbol dominant. Transparent canvas outside the rounded tile, genuinely alpha transparency. No lettering, no words, no Google wordmark, no screen outline, no logo sheet, no mockup, no perspective, no watermarks. Professional independent app identity inspired by the reference's wireless concept, not a reproduction.
